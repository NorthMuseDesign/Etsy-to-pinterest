Privacy Policy

Last updated: October 24, 2026

About this application

NorthMuse Etsy Pin Manager is a personal automation tool used to manage and publish Pinterest Pins linking to products from the NorthMuseDesigns Etsy shop.

Information processed

The application may process Etsy product information, including listing titles, URLs and images, as well as the Pinterest account information and permissions needed to publish Pins and retrieve account reports.

How information is used

Information is used only to support the application's Etsy-to-Pinterest publishing and reporting functions. It is not sold to third parties.

Third-party services

The application may interact with Etsy, Pinterest and GitHub Actions to retrieve listing information and run automation. These services are subject to their own privacy policies and terms.

Security and retention

API credentials are intended to be stored as protected GitHub repository secrets, not in the source code. Access tokens and other information will be retained only as needed for the application's operation and maintenance.

Your choices

Access to connected accounts can be revoked through the relevant service's account settings. You can also stop using the application and remove stored credentials.
